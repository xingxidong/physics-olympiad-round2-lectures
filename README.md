## 源码与编译

第一编主文件为 `output/book/大学物理中的数学方法.tex`。第三编位于 `output/latex/动力学综合_手写讲义修订版/`；其余各编位于 `output/book/` 下相应目录，主文件均为 `main.tex`。TikZ图与正文一起保存，引用文件的相对目录须保持不变。

使用支持中文的TeX Live环境，以XeLaTeX编译。例如安装了 `latexmk` 时，在仓库根目录执行：

```sh
latexmk -xelatex -cd 'output/book/光学进阶/main.tex'
```

总前置位于 `output/book/总合订本/`。发布的全书PDF由总前置和十个分册合并，并保留分册页码、书签和内部链接；单独编译总前置只会得到前言、总目录与主题索引。

## 计算实验

[experiments/](experiments/) 包含离线实验页面、Python复算脚本和参考数据。下载仓库后，直接打开 `experiments/打开实验.html` 可运行单摆、共振、耦合振子、阻力抛体及数据拟合实验。

`核验实验.py` 需要NumPy、SciPy；`事件与抽样实验.py` 只使用Python标准库。实验中的AI任务用于描述模型、参数和检验要求，可交给代码生成工具实现；离线页面本身不连接在线AI服务。
